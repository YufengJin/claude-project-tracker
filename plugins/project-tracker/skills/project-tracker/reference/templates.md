# 文件模板

所有日期用 `YYYY-MM-DD`。字段名固定，不要改名、不要省略，空的写 `无`。

## charter.md

```markdown
# <项目名>

Slug: <slug>
Created: YYYY-MM-DD
Status: 进行中

## 目标
<一到三句。解决什么问题、为谁>

## 完成标准
- [ ] <可判定的条件。打勾必须对应 journal 里的证据条目>
- [ ] <...>

## 不做
- <明确排除的范围>

## 约束
- <不能动的接口、deadline、兼容版本、资源限制>

## 验证方法
<怎么知道做对了：测试命令、对照实现、基线数据、人工检查步骤>

## 起点
<开始时的现状与基线数据，用于日后对比>

## 协作约定
- <用户对工作方式的要求，例如"改动前先跑测试"、"不要动 X 目录"、"用中文汇报">

## Open questions
- <未定的事。定下后移到对应章节，并在 journal 记一条>
```

## journal.md

只追加到文件末尾。

```markdown
## YYYY-MM-DD · session N
Goal:     <这次打算做什么>
Did:      <实际做了什么>
Result:   <成功 / 失败 / 部分。必须带证据：命令、输出、数字变化>
Learned:  <之前不知道、现在知道的。失败的路写在这里，并同步到 state 的"别再试">
Commits:  <相关 commit 短哈希或分支，无则写 无>
Next:     <下一步，具体到能直接动手>
Open:     <新冒出来的问题>
```

`Result` 反例："完成了"。正例："完成。`pytest tests/ -q` 从 12 failed 降到 0 failed，耗时 41s"。
`Learned` 反例："学到很多"。正例："Tsit5 对这个 ODE 太刚性会发散，换 Kvaerno5 后收敛"。

## state.md

可覆盖。硬上限 100 行。

```markdown
# 当前状态
Updated: YYYY-MM-DD (session N)

## 一句话概括
<现在在哪>

## 快速启动
```bash
<恢复工作环境和验证现状所需的命令，例如 build / test / 启动服务。冷启动会话第一件事跑这个>
```

## 已完成
- <条目。超过 10 条就压缩进 archive/，这里留一行摘要>

## 进行中
- <条目 + 当前卡在哪>

## 别再试
- <已证实走不通的路 + 为什么。来自 journal 的 Learned。这是 state 里最值钱的一节>

## 已知问题
- <条目>

## 下一步
1. <具体到能直接动手>
2. <...>
```

## plan.md

可重写。写"打算怎么做"，与 state 的"现在在哪"分开。

```markdown
# 计划
Updated: YYYY-MM-DD (session N)

## 策略
<一段：整体思路和顺序为什么这样排>

## 步骤
- [x] 1. <已完成的步骤保留打勾，让人看到进度>
- [ ] 2. <当前步骤> ← 进行中
- [ ] 3. <...>

## 风险
- <可能翻车的地方和预案>
```

重大方向调整：先在 journal 记一条为什么改，再重写此文件。

## decisions.md

只追加。编号递增。

```markdown
## ADR-0001: <决策标题>
Date: YYYY-MM-DD
Status: 采纳

**背景**：<当时面对什么情况>
**决定**：<选了什么>
**否决的方案**：<考虑过但没选的，以及为什么>
**假设**：<这个决定依赖哪些前提。前提变了就要重审>
**来源**：用户指定 | Claude 建议且用户同意 | Claude 推测
```

推翻旧决定：新增一条 ADR，把旧条目 `Status` 改为 `已推翻（见 ADR-00NN）`。这是对已有条目唯一允许的修改。

## INDEX.md

```markdown
# 项目索引

| Slug | 名称 | 状态 | 最后更新 | 一句话 |
|------|------|------|----------|--------|
| auth-refactor | 用户认证重构 | 进行中 | 2026-09-08 | JWT 迁移做完，等灰度 |
| q3-pipeline | Q3 数据管线 | 已完成 | 2026-08-21 | 全部验收通过 |
```

状态取值：`进行中` `暂停` `已完成` `已放弃`。

## ACTIVE

纯文本一行，只有 slug，无换行以外的其他内容：

```
auth-refactor
```

## archive/state-YYYY-MM-DD.md

从 state.md 挪出的旧"已完成"条目，原样粘贴，顶部加一行 `Archived from state.md on YYYY-MM-DD`。
